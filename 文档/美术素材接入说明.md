# 美术资源接入与需求

当前工程是原生 Android Activity + WebView；界面由 HTML、CSS、原生 JavaScript 构成，探索使用 Canvas。无 React/Vue。`game.js` 管理核心玩法、章节与 localStorage.wujia 存档；`ui.js` 管理弹窗与现有按钮；`home-polish.js` 保留真实存档卡；新增 art-menu 层只负责主菜单素材与视觉。未更改剧情、角色能力或存档格式。

所有素材放入 `源码/吴家村传说/assets/art/`，然后在 `assets/art-config.js` 中把 null 改为相对路径，例如 `art/backgrounds/menu-night.webp`。缺图或加载失败时保留代码占位层，主菜单不再调用封面。图片内不得含 UI 文字、按钮或 Logo。

必须补充：背景、背影立绘。其余资源均有可交互的代码默认样式。当前角色层显示虚线占位框，不使用封面角色替代。

`art-config.js` 的 layout 独立配置背景缩放和焦点、角色位置/高度、菜单宽度。背景使用 cover 等比裁切；角色使用 contain 保持完整；菜单使用视口单位与安全区。按钮支持悬停、键盘焦点、选中、触屏按压，继续复用原来的点击处理函数。上下键切换菜单，Enter 激活按钮。设置中关闭动效或选择流畅画质会禁用氛围动画。

素材到齐后需对 16:9 平板及荣耀 WIN 超宽横屏检查画面焦点与人物落脚位置；当前阶段仅完成资源结构和代码接入接口，不宣称最终美术已验收。
