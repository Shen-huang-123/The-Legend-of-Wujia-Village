# 表情差分参考

## 第二版透明合集

expression-sheet-transparent.png 为后续收到的 2048×768 RGBA 合集，已确认背景像素 Alpha=0，具有真实透明通道。包含李寒卓四种表情和吴家聪三种表情。

人物之间仍有衣摆、飘带、头发和剑刃相互覆盖，部分外侧衣摆贴近画布边缘。简单裁切无法恢复被遮挡部分，因此不拆成标称完整的正式立绘。此版保留为透明参考，未替换现有六张素材，未接入旧剧情。请从绘图工具将七个人物分别以独立图层导出，同一角色保持画布与站位一致。

## 第一版棋盘格合集

expression-sheet-reference.png 为用户提供的 1536×1024 合集。

检查结果：Format24bppRgb，无 Alpha 通道。灰白棋盘格已经烘焙进图片，并非透明背景。人物衣摆、飘带接近或跨越分区边界，不能通过简单矩形裁切得到完整透明立绘，也不能据此保证表情切换不跳位。

此图仅保留为参考，不替换现有六张 PNG，不绑定旧剧情。

正式差分请提供独立、真实 RGBA 透明 PNG：

- li-hanzhuo-calm.png：冷静
- li-hanzhuo-angry.png：愤怒
- li-hanzhuo-shocked.png：震惊
- li-hanzhuo-sad.png：悲伤
- wu-jiacong-calm.png：平静
- wu-jiacong-solemn.png：沉重

建议每张画布 1600×2400。同一角色各差分必须保持相同画布、身体姿态、人物缩放、站位与脚底基线，只改变必要表情；不能逐张自动裁边。衣摆、头发和特效应完整保留在画布内。导出时关闭棋盘格背景图层。
