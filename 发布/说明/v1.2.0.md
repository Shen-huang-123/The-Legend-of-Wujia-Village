# v1.2.0 · 暗黑国风八界面

- 版本：1.2.0（versionCode 4），最低支持 Android 8.0。
- 安卓桌面图标及统一场景底图使用项目根目录的 `软件封面.png`。
- 八套横屏界面可独立操作：主界面、章节选择、探索、背包、地图、图鉴、剧情、设置暂停。
- 黑红配色、古铜描边、符咒、血月、红灯笼与水墨笔触保持统一。
- [最新版安装包](../../安装包/最新版/吴家村传说-v1.2.0.apk)。
- 已通过 JavaScript 语法检查、APK v2/v3 签名校验及浏览器交互验收。

原计划通过内置 imagegen 生成新的无文字场景底图，但服务连续返回不可用。本版使用用户指定的现有封面图；按钮、面板、文字和交互均由应用代码实现。
