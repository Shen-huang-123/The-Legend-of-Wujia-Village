## 开发与验证

在 `源码/吴家村传说` 目录运行：

```powershell
node test-blood-debt.cjs
.\build.ps1
```

测试脚本覆盖七章剧情、对话回退、历史记录、快速点击、道具生命周期、章节解锁和结局存档。构建脚本会生成 `release/Wujia-Legends-1.2.3.apk`，本地需安装 Android SDK 35 与 JDK。

`build/`、`release/` 与本地签名密钥不会提交到 Git。仓库内仅保留 `安装包/最新版` 中唯一推荐安装包。

当前剧情已通过模拟 DOM 流程测试与 APK v2/v3 签名校验。

## 当前功能

- 七章《血债神兵》剧情、章节选择、存档与重游。
- Galgame 全屏剧情演出、逐字显示、上一句、历史、自动播放、跳过和隐藏 UI。
- 背景、人物、道具独立分层，支持表情切换、道具生命周期和轻量动态演出。
- 一指、闪现、腾空能力与 Android 多点触控探索 HUD。
- 16:9、超宽横屏及荣耀 WIN 等低高度横屏适配。

## 操作与存档

触屏或 A/D、方向键移动，J一指、K闪现、空格腾空。剧情点击先显示全文，再推进下一句；支持跳过。沿用本机七章通关记录，已解锁章节可重游，卸载会清除本机数据。
